# BigDvToolBox v1.0.9

- 新增自由拼版：容器独立放入 PDF、选择页码、复制、替换和清空，允许留空。
- 拼版方式移至配置下方，便于直接切换重复拼版与自由拼版。
- 调整容器交互：单击选中、双击选择文件、右键选页和清空；按住左键拖动复制，悬浮预览使用小缩略图。
- 加载 PDF 时提示未嵌入字体，导出时可选择“转曲后保存”。
- 新增打印诊断日志：记录请求和驱动返回的纸张尺寸、DPI、位图大小、各阶段耗时、异常及 HRESULT。
- 打印任务带短编号，尝试补收集提交后一分钟内对应的 Windows 打印错误事件。
- 保持自包含 x64 绿色版，解压后运行，开发者 YanWei。随附授权、对应项目源码、Ghostscript 10.07.1 完整源码及 SHA-256 清单。

## 打印问题反馈

此版本增加诊断记录，用于排查部分打印环境中出现的尺寸缩小、打印慢和队列发送失败；尚未确认同事的 EPSON L3250 问题已修复。

1. 在本工具中复现一次直接打印，记下大致时间及打印队列中的短编号。
2. 保持软件打开约一分钟，让日志尝试补收集对应的 Windows 打印错误事件。
3. 按 Win+R 打开 `%LOCALAPPDATA%\BigDvToolBox\Logs\Printing`，提供本次 `print-*.log`。页面状态也会显示完整日志路径，可选中复制。

若系统不允许读取打印事件，日志会记录读取失败，其他打印诊断仍可使用。

## 下载

日常使用下载 `BigDvToolBox-1.0.9-win-x64.zip`，完整解压后运行 `BigDvToolBox.exe`。
无需另外安装 .NET 或 Windows App SDK；OCR 原生组件仍需要 VC++ 2015–2022 x64 运行库。

其余附件为对应项目源码、Ghostscript 源码、发行说明和校验清单。升级时解压至新目录，原有本地配置保留。
