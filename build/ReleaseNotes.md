# BigDvToolBox v1.0.12

- 改进打印机离线、取消预览后重试的处理：驱动参数读取移到后台，增加取消和超时控制，忽略旧预览结果和旧任务回调。
- 连续重试共用驱动读取通道，避免堆积未结束的连接调用。
- 可打印区域和坐标转换限定在打印会话内；切换打印机、纸张或方向时重新读取参数并刷新预览，最终提交前再次计算。
- 版式边距始终相对于整张纸计算，硬件不可打印边距只负责裁切，不额外叠加到设计边距上，也不固定补偿 3 mm。
- 不回写拼版配置，不改变导出 PDF 的页面尺寸、容器位置或内容。默认打印日志保持关闭。
- 已通过 75 项相关测试，包含离线阻塞、取消重试、不同硬件边距及导出隔离；未发送真实打印任务，实机效果仍需核对。
- 自包含 x64 绿色版，开发者 YanWei。随附授权、对应项目源码、Ghostscript 10.07.1 完整源码及 SHA-256 清单。

## 本次实测

请核对打印机未连接时取消、重新连接后再次预览，以及连续取消后重试能否正常退出和恢复。
边距可分别设置为 0 mm 和 10 mm，打开容器边框后用尺子核对位置、容器尺寸和间距。
无边距模式按驱动实际提供的范围处理；若驱动在预览时尚未报告硬件边界，最终以提交时的参数为准。

## 下载与升级

下载 `BigDvToolBox-1.0.12-win-x64.zip`，完整解压后运行 `BigDvToolBox.exe`。
升级前关闭旧版，解压到新目录后启动，原有本地配置保留。
无需另外安装 .NET 或 Windows App SDK；OCR 原生组件仍需要 VC++ 2015–2022 x64 运行库。
其余附件为对应项目源码、Ghostscript 源码、发行说明和校验清单。
