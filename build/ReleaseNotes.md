# BigDvToolBox v1.0.11

- 默认关闭打印诊断：正常使用不再生成打印日志、不显示日志路径，也不启动后台打印事件收集。
- 普通打印任务名称不再附带诊断编号。
- 明确采用 asInvoker 权限声明，按启动者权限运行，不主动请求管理员权限。建议从普通资源管理器双击启动。
- 保留实际尺寸 1:1 打印、超出可打印区域裁切、预览裁切提示及驱动缩放校验。
- 自包含 x64 绿色版，开发者 YanWei。随附授权、对应项目源码、Ghostscript 10.07.1 完整源码及 SHA-256 清单。

## 下载与升级

下载 `BigDvToolBox-1.0.11-win-x64.zip`，完整解压后运行 `BigDvToolBox.exe`。
升级前关闭旧版，解压到新目录后启动，原有本地配置保留。
无需另外安装 .NET 或 Windows App SDK；OCR 原生组件仍需要 VC++ 2015–2022 x64 运行库。

旧版本生成的日志不会自动删除，如不再需要，可自行删除 `%LOCALAPPDATA%\BigDvToolBox\Logs\Printing` 中的日志文件。
其余附件为对应项目源码、Ghostscript 源码、发行说明和校验清单。
