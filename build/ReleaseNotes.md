# BigDvToolBox v1.0.13

- 新增批量重命名模块，文件与文件夹分开管理，支持替换文字、添加文字、按位置删除、删除指定字符、大小写转换和添加序号。
- 方法可以重复添加、独立配置，并按列表顺序组合执行；支持启用、禁用、上移、下移和独立手柄拖拽排序。
- 支持方案列表预设的保存、加载、JSON 导入导出和删除；删除预设后保留当前方法和参数，便于继续编辑。
- 文件和文件夹预览使用原生 TableView，支持固定列头、调整列宽、固定行高和文本省略显示。
- 提供重命名预览、名称冲突检查、两阶段改名，以及失败或取消后的恢复处理。
- 重命名核心与 WinUI 界面分离。
- 自包含 x64 绿色版，开发者 YanWei。随附授权、对应项目源码、Ghostscript 10.07.1 完整源码及 SHA-256 清单。

## 验证与已知限制

应用测试通过 199 项，跳过 1 项已知 OCR 样例测试；重命名核心测试 28 项全部通过。
本版本使用 Windows App SDK 2.5.4-experimental 的 TableView，其 API 仍处于实验阶段；后续升级 SDK 时可能需要适配。
当前构建环境未进行界面自动化实测，拖拽排序和 TableView 的实际交互仍需在运行时核对。
文件系统执行支持失败恢复，但不提供进程崩溃或断电后的持久化恢复。

## 下载与升级

下载 `BigDvToolBox-1.0.13-win-x64.zip`，完整解压后运行 `BigDvToolBox.exe`。
升级前关闭旧版，解压到新目录后启动，原有本地配置保留。
无需另外安装 .NET 或 Windows App SDK；OCR 原生组件仍需要 VC++ 2015–2022 x64 运行库。
其余附件为对应项目源码、Ghostscript 源码、发行说明和校验清单。
