# BigDvToolBox v1.0.14

- 新增公共文件池：标题栏入口打开右侧临时浮层抽屉，不挤占功能页面宽度。支持添加、拖入、搜索、类型筛选、多选和手动加入当前功能。
- OCR 重命名、批量重命名、PDF 字体转曲和图片处理共享已导入的输入文件，各模块保留独立的任务、参数和勾选状态。
- 文件池只收录文件。导入文件夹默认收录直属文件，可选递归并取消；移出和清空文件池不会删除磁盘文件或已有任务。文件池仅在本次程序运行期间共享。
- OCR 支持从文件池追加跨文件夹的 PDF 和图片；重命名及文件夹改名同步输入路径。同一文件被其他模块使用时会提示稍后重试。
- PDF 转曲成功后，用输出 PDF 替换池中的原 PDF，磁盘原件保留；失败、取消项保留原文件。图片处理的输出不进入文件池。
- OCR 增加模型目录、语言和识别选项配置，使用 LSTM 引擎并检查所选语言模型是否能加载。
- 自包含 x64 绿色版，开发者 YanWei。随附授权、对应项目源码、Ghostscript 10.07.1 完整源码及 SHA-256 清单。

## 验证与已知限制

应用测试通过 228 项、跳过 2 项（外部语言模型样例及已知 OCR 样例）；重命名核心 28 项全部通过。
Windows App SDK 2.5.4-experimental 的 TableView 仍为实验 API，后续升级 SDK 时可能需要适配。
当前构建环境未进行界面自动化实测；抽屉收起、焦点恢复、窄窗口及明暗主题效果仍需运行时核对。
重命名支持失败恢复，但不提供进程崩溃或断电后的持久化恢复。

## 下载与升级

下载 `BigDvToolBox-1.0.14-win-x64.zip`，完整解压后运行 `BigDvToolBox.exe`。
升级前关闭旧版，解压到新目录后启动，原有本地配置保留。
无需另外安装 .NET 或 Windows App SDK；OCR 原生组件仍需要 VC++ 2015–2022 x64 运行库。
其余附件为对应项目源码、Ghostscript 源码、发行说明和校验清单。
