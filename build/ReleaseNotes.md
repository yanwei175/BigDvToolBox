# BigDvToolBox v1.0.10

- 直接打印按实际尺寸 100% 放置印张，超出驱动可打印区域的部分裁切，保留标签及容器的实际尺寸。
- 系统打印预览用灰色遮罩和虚线显示驱动报告的裁切范围，辅助标记不会进入实际打印内容。
- 驱动在预览阶段未提供硬件边界时显示说明，最终以提交阶段返回的可打印范围裁切。
- 打印诊断日志增加预览和最终打印票据、缩放及多页合一参数，以及实际放置与裁切范围。
- 最终票据明确启用自动缩放或每张纸多页时，停止提交并提示改为实际大小（100%）、每张纸一页。
- 保留纸张尺寸、DPI、位图大小、各阶段耗时、异常及 HRESULT 日志，以及提交后一分钟内对应 Windows 打印错误事件的收集。
- 保持自包含 x64 绿色版，解压后运行，开发者 YanWei。随附授权、对应项目源码、Ghostscript 10.07.1 完整源码及 SHA-256 清单。

## 打印问题反馈

此版本用于核对实际尺寸打印和硬件边界裁切，并排查打印慢、队列发送失败等问题；尚未进行 EPSON L3250 实机验证。
应用按原尺寸绘制；若驱动未提供标准缩放字段或票据读取失败，日志会注明无法核实驱动缩放，不能据此保证驱动后续处理不会改变尺寸。

1. 在本工具中复现一次直接打印，记下大致时间及打印队列中的短编号。
2. 保持软件打开约一分钟，让日志尝试补收集对应的 Windows 打印错误事件。
3. 按 Win+R 打开 `%LOCALAPPDATA%\BigDvToolBox\Logs\Printing`，提供本次 `print-*.log`。页面状态也会显示完整日志路径，可选中复制。
4. 用尺子核对打印结果中的容器尺寸、横竖间距，并同时提供打印机型号、纸张设置和结果照片。

若系统不允许读取打印事件，日志会记录读取失败，其他打印诊断仍可使用。

## 下载

日常使用下载 `BigDvToolBox-1.0.10-win-x64.zip`，完整解压后运行 `BigDvToolBox.exe`。
无需另外安装 .NET 或 Windows App SDK；OCR 原生组件仍需要 VC++ 2015–2022 x64 运行库。

其余附件为对应项目源码、Ghostscript 源码、发行说明和校验清单。升级时解压至新目录，原有本地配置保留。
